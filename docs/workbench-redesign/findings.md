The baseline overview gives the question a narrow right inspector while a sparse project card occupies the main canvas. Dataset provenance is a long form; the question is separate from its required context. Existing IDs, operator decisions, source/receipt verification, immutable presentation children and scientific workspace flows are valuable and will be retained.

Question submission registers an exact local H5AD and declaration set. Planning is bounded, not a general conversation service. state_history contains actual transitions; follow-ups can draft a fresh question but cannot silently reuse approval or run selected-population computation.

Existing artifact download can serve plot_data.path after bundle verification. Other plot catalog entries describe requirements and do not prove implemented producers.
