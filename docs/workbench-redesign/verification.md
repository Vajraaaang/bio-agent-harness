# Engineering walkthrough and verification

## Working implementation

The existing local workbench now places the research question and authentic recorded conversation beside its context/artifact canvas. The responsive shell, typography, component states, professional copy, native focus behavior and light/dark themes use the user's grey/black/white UI palette. Scientific color encodings still match retained category or continuous-scale records.

The new conversation module displays retained proposal source, input preview, operator review, exact controller transitions, failures and appropriate next navigation. It does not fabricate a chat stream or reasoning. Follow-ups hydrate the exact source dataset/declarations or clear unresolved context before plan preparation. Selected IDs enter a reviewable new question draft; no scientific action runs from a plot control.

The new scientific figure module renders verified saved QC/UMAP coordinates. It provides responsive zoom/pan, box/lasso selection, category filtering/recoloring, point display controls, reset/fullscreen, exact-ID table pagination/search, and SVG/2×PNG/CSV/JSON exports. Existing verified images and supervised immutable presentation revisions remain available. Unknown/invalid artifacts fail to the original-image path. Navigation destroys/remounts one active renderer with stale-response guards.

The Python change composes three explicitly shipped local assets into the original nonce-protected page. It adds no API authority, CSP exception, remote script, framework or scientific method. Wheel/source-package allowlists name the exact new assets. Numerical methods, resource limits, operator approval, authentication, workflow admission and sealed history remain unchanged.

## Review findings corrected

1. Returning to results could leave both figure hosts hidden. Results entry now restores/remounts, original images remain available, and generation guards reject stale requests. An isolated regression and a real browser Execution → Figures journey cover it.
2. A follow-up from run A could inherit stale form data from run B. Drafting now binds the retained source path/hash/declarations when that source is known and clears unresolved context. Regression and browser source-form inspection cover it.
3. CSV export quoted negative numeric coordinates as formula-like strings. Finite numeric values remain numeric while dangerous textual cells are neutralized; the figure regression covers both.
4. Error states exposed raw tracebacks in the primary interface. They now show a concise checksum/source reason, with raw failure records retained in expandable evidence and Execution Log. The new regression first failed, then passed.
5. Small-screen flex order followed the old DOM instead of the visual conversation-first intent. The actual DOM now places the conversation before the canvas, improving both visual and assistive reading order.

An earlier full run had one obsolete assertion requiring the old orange CSS accent; that assertion was updated for the user's explicit monochrome requirement. Two earlier parallel numerical checks correctly rejected source edits during execution and passed unchanged targeted repeats after source freeze. Original JUnit/evidence is retained; these were not treated as scientific successes.

## Limits and next supported work

This is a working redesign within the current backend's scientific scope. No general multi-turn conversational agent, upload service, arbitrary selected-cell inference, DE/volcano/MA/gene-expression producer, million-cell GPU renderer, authenticated scientific reviewer or clinical qualification is introduced. Available plot families remain deliberately narrow. Bulk workflows and opt-in scientific workspace permissions retain their existing interfaces.

Next work should be driven by actual validated output adapters and measured workloads: broader figure producers, durable conversational follow-ups with typed population references, larger-data transport/rendering and qualified assistive-technology testing. Those capabilities need their own backend contracts and evidence rather than presentation-only promises.
