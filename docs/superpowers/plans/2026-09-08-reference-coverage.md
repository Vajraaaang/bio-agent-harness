# Reference-normalization coverage diagnostic plan

> Execute in the authorized clinical-platform work. Use the requesting-code-review workflow for an independent review before fitting. The coordinator owns the new research scripts; the reviewer is read-only. Preserve the existing source and sealed evidence. No Git base is invented for this uncommitted checkout.

**Goal:** Measure the current prespecified-reference candidate's admissibility, bias and interval coverage on fresh synthetic cohorts, compared with current whole-panel RLE on the same data.

**Architecture:** New research-only preparation, execution and analysis scripts live under `results/reference-coverage-2026-09-08/`. They call the unchanged governed native CLI. They freeze protocol, source, inputs, truth, plans and configured-key fixture approvals before fitting. Main measurement is separate from a four-cohort execution preflight. A successful measurement process is not a statistical or clinical pass.

**Tech stack:** Current DevHarness 0.4.8, fixed native DESeq2 1.52.0/R 4.6.1 image, NumPy PCG64, Patsy, SciPy exact binomial intervals, existing configured-key authority and semantic verifier.

## Design and alternatives

Running more historical whole-panel cohorts would improve precision for an already adverse procedure without testing the new candidate. A bootstrap changes the interval estimator and would need a distinct prespecified method design. This study first evaluates the actual reference-set candidate, including its fail-closed all-positive eligibility policy. It changes no estimator or clinical acceptance margin.

The two settings are n=24/dispersion=0.2 and n=48/dispersion=0.8. Each has six equally spaced times, balanced batch 0/1, a full-rank fixed centered natural cubic spline with three temporal columns, and a reduced intercept/batch design. The effect is the population-expression log2 contrast between time 5 and time 0 at batch 0, excluding library-factor change. Independent synthetic biological units are generated by construction; this does not verify independence of future clinical samples.

There are 80 genes and 32 hypothesis genes. The existing exact-model-space curve generator creates 16 nulls and four genes in each of positive linear, negative linear, endpoint-neutral nonconstant and nonlinear-positive groups. Ordinary gene means are log-uniform from 2 to 600; batch coefficients are Normal(0,0.35). Log library factors are Normal(0,0.7), centered to geometric mean one. Eight references, g072-g079, have generating mean 1000 and zero temporal and batch coefficients, prescribed before count sampling. Counts follow the NB2 model with the setting's constant dispersion. This deliberately specified synthetic reference does not select or qualify a clinical housekeeping panel.

Whole-panel RLE uses governed effect schema 4. Reference RLE uses governed effect schema 6 with these eight declared genes and `all_positive` policy. Both use the same source, inputs, hypothesis family, mean dispersion trend, fixed LRT, numeric endpoint contrast and nominal 95% normal-Wald interval. No generating factors, generating dispersions, coefficients, selected hypothesis or truth file is supplied to the native fitting request. Every arm is attempted even if the other arm refuses a cohort. No redraws, retries, dropped failed cohorts or pilot/main pooling.

## Frozen measurement protocol

- Preflight seed 2026092018, two cohorts per setting; main seed 2026092017, 256 cohorts per setting. Separate mean/library/batch/selected-gene/count RNG streams per cohort. Seeds and sample size are fixed before preflight outcomes.
- Primary per-arm measures: planned, attempted, verified complete, eligibility/refusal rate, one independently selected hypothesis's coverage among verified complete cohorts, exact pointwise 95% binomial interval and Monte Carlo SE. The selected hypothesis is uniform over the declared 32 IDs, uses its own RNG stream independently of count/parameter generation, and is identical for the two arms of a cohort. No gene is selected using fitted results.
- Missingness bounds: selected covered/planned to (selected covered + planned minus verified complete)/planned. Failed and unattempted outcomes both remain missing. These describe possible coverage proportions over the complete planned cohort set; accepted-only coverage is explicitly conditional on successful execution/admission. Attempted and unattempted counts are reported separately.
- A main-study diagnostic undercoverage flag is assessed only when all 256 planned cohorts for that setting/arm were attempted and verified complete. An infrastructure-stopped prefix cannot satisfy this requirement. The flag is true only if the one-sided exact upper bound at alpha=0.05/4 is below 0.95. Four cells-by-arms form this family. Absence of a flag is not acceptance. With 256 independent cohorts, nominal-coverage Monte Carlo SE is about 1.36 percentage points; missingness makes precision worse. The separate preflight never receives a main-study diagnostic flag.
- Secondary cohort-level measures: mean error, mean squared error, interval width and within-cohort coverage over the 32 hypotheses; genes are not independent Monte Carlo replicates. Paired differences use only cohorts with both arms verified complete, with explicit paired denominator and t-based Monte Carlo intervals labelled approximate/conditional. Also retain discordant selected-hypothesis coverage counts.
- Record the analytical probability that all reference counts are positive, given each frozen generating mean matrix, and actual eligibility. This describes the declared generator and does not alter counts, admission policy or inference.
- Failure taxonomy retains exact CLI, outcome and verifier errors. Incorrect study helpers remain retained separately. Infrastructure failure can halt unscheduled work, which is reported as unattempted; it must not be silently treated as a completed negative result.
- Use at most two concurrent native CLI processes, each one CPU/1 GiB/60-second native deadline. Outer CLI watchdog 180 seconds; timeout is an infrastructure failure with unproven cleanup until checked. Require at least 5 GiB free disk before scheduling. No image pulls, model-service calls, private clinical data or credential transfer.
