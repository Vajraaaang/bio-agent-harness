Research question

What change in state A abundance does the donor-level model report for treated versus control donors, relative to the model’s reference cell state?

Cells are measured observations. Donors are the independent biological units.

Findings

The supplied scCODA summary reports a higher state A ratio relative to the reference in treated donors.

Workflow and checkpoints

These stages describe how the local Workbench separates data checks, analysis decisions, and evidence review.

Donor-aware composition

  1. Intake Identify count measurements, donor labels, and treatment groups.
  2. Quality control Review capture-level cell counts, filtering, and doublet flags.
  3. Plan review Record the contrast and reference, then check whether the donor design supports the comparison.
  4. Model fit Use donor-by-state counts to estimate composition changes relative to the reference.
  5. Evidence review Inspect diagnostics and retain outcomes, retries, and unresolved assumptions.
