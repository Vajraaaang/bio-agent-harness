Statistical limits

Adverse findings remain visible

  • Unequal variances invalidate the current Gaussian calibration assumptions.
  • Native count interval undercoverage has been observed.
  • BH/BY calculations do not repair invalid marginal tests.
  • Selection-adjusted endpoint intervals and longitudinal inference remain unqualified.

Clinical and operational limits

Code alone cannot close these gates

  • Approved assay and clinical context of use
  • Independent analytical and clinical validation
  • Administered human identity and quality approval
  • Qualified deployment, recovery and protected retention
Open qualification requirements

A built notebook is not an executed Colab run. Protocol activity is not a passing agent benchmark. Hashes detect changes relative to a retained anchor; they do not independently authenticate the operator or prove event completeness.
