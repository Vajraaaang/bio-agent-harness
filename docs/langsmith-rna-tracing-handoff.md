## Constraints the next engineer must preserve

- Local ledgers/captures/artifacts/checkpoints are authoritative; LangSmith is best-effort derived observability. Keep `reserved`, actual dispatch, valid capture, completed, incomplete, failed, cancelled and uncertain distinct. Known tails remain charged; missing usage/timing/cost remains unknown.
- Provider cost uses a closed value/currency/basis/source-alias record. Actual charge and historically recorded estimate remain distinct; partial receipts cannot become complete totals, absent cost cannot become zero, and different currencies/bases cannot merge into one scalar. No current-price backfill or exchange-rate conversion.
- Redact by constructing an allowlisted payload. No matrices, gene lists, prompts/responses/thoughts, objective/free-text summaries, sample/donor/patient identifiers or their deterministic hashes, paths, free error text, headers, credentials or grants. Hidden truth/goldens/grader fields are never read or exported. Use opaque random aliases and a local-only evidence map. Synthetic/public-processed scope only; clinical/unclassified scope rejects before reads/transport.
- Explicit context sidecars are correlation receipts outside existing packets, exact reservations/cursors and answer schemas. They cannot authorize model, numerical or retrieval execution. All sibling roots/assignments remain isolated and coordinator-composed attribution stays accurate.
- Durable outbox persists before send. A timeout or crash after send becomes uncertain and blocks blind resend; remote duplicate handling is unqualified until a separately authorized synthetic pilot. Export recovery never reexecutes science.
- Live coordinator starts/ends are sanitized before outbox persistence and handled by a separate exporter process. Only the exporter receives credentials. Parent starts must be acknowledged before child starts; finish patches the same span ID under an immutable revision. Source cancellation/late completion history is preserved. Exact reviewed post-run payload approval and a frozen live-session/schema/scope authorization are distinct controls.
- Preserve negative/invalid epoch evidence and wall/monotonic disagreement locally. Same-process monotonic intervals support duration; causal IDs/sequences support ordering. Cross-worker clocks cannot establish global elapsed ordering, and a display anchor cannot become measured latency.
- Preserve the immutable gene/contrast hypothesis family, numerical declarations and result identity. Each genuine declared fit attempt runs once; explanations share numerical evidence. Preserve unit/rank/contrast/confounding/repeated-specimen warnings/vetoes, p/q requirements, method-family rules and evidence-scope distinctions.
- Recorded operator permission, scientific review, expert validation and authenticated human/clinical approval remain separate. Trace success/DAG hashes confer neither biological validity nor clinical approval.
- Read-only replay stays inert. New preview writes only a fresh separate directory, checks unchanged source evidence, and never launches, fits, retrieves, summarizes or initializes source stores.

## Acceptance, risks and decisions

Start with bounded synthetic software fixtures and fake transports: 0/1/2 children, pre-fit/post-fit, capture gaps, unknown launch, cancelled tail, result-commit loss, inherited tracing rejection, tampering, privacy canaries, storage caps, exporter crash/retry/duplicate/lease cases. Use spies and store manifests to prove zero extra execution; compare local off/on behavior only when optional receipts are implemented. Exact future commands, file ownership, APIs, schemas, thresholds and failure matrix are in the plan. No verification tests were run while writing these files.

Main risks are falsely treating reservations as dispatch, omitting preflight/tail costs, inventing timing from display anchors, leaking metadata/errors, weakening the native gate, and relabeling a changed runtime as qualified. Remote service failure must not alter scientific outcomes; required local audit failure retains its current fail-closed behavior. Outbox ambiguity requires explicit reconciliation rather than a successful-looking retry.

Later rollout decisions: deliver the first qualification increment alone or authorize the full staged local/live implementation; select hosted region/workspace/project or separately qualified self-hosting; freeze overhead, live visibility, storage and retention ceilings before measurement. Hosted/self-hosted rollout is controlled and changes no account now. First hosted pilot needs separately approved synthetic payload/upload and then a frozen live software-fixture session with explicit dashboard/privacy/dedup/start-patch verification; it establishes service behavior, not scientific quality.

The user requested a plan and handoff, so the current authorized work ends at these reviewable documents. A future implementation request can name Phases 0–3. A scientific model/data campaign or external upload still needs its own concrete scope and existing admission controls.
