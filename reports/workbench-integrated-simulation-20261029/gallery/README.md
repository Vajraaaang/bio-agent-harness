# Workbench plot gallery

These 18 plots were exported with the current workbench’s own **PNG · 2×** control. They use six fictional, explicitly synthetic projects with unequal batch sizes. They are generated presentation data, not biological observations or scientific trial results. All selected points are drawn without downsampling. Each image retains the simulation label, project name, exact plotted population and seed.

The [manifest](manifest.json) records source/image hashes, project configurations, counts and export details. No model service or live trial was used.
