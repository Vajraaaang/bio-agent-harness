# Comparative evaluation and independent review

At E4, define the estimand, candidate methods, budgets, inclusion criteria, partition digests, primary metric, uncertainty, failure handling and winner/abstention rule before viewing results. Keep test partitions embargoed. Compare single-cell foundation models (scFM) to classical baselines on identical donor-grouped splits, features, resource limits and endpoints. Check training overlap, null false discoveries and performance in the intended regime. Timing or retained rows alone cannot select a winner.

Use `list_kernels_and_methods` to check actual runtime support. For Tier 2 exploratory code, bind source, exact image, limits, declared input/output contract, seeds and package versions using `freeze_analysis_plan`. Use local synthetic fixtures for preflight and keep execution offline. ADR-19 requires per-plan review by default. Only a recorded out-of-band operator policy can authorize eligible public/synthetic exploratory Tier 2 work automatically. Private/clinical work requires local offline review. E5 confirmatory fits require their own review. Preserve blockers and immutable approval identity.

Request the Independent Critic through `manage_research_aim` with action `request_critic_review` and the current session revision. Use a verifier independent of the author. Gate 1 is outcome-blind. Supply custody, donor identities, rank and contrast diagnostics, calibration regime, frozen plan and declared falsification probes before E5. Gate 2 follows the frozen fit and post-fit E3 checks. Supply receipts, p/q bounds, tested-universe identity, donor influence, alternatives, negative controls, missing probes and plot/sidecar consistency. Record reviewer origin, verdict, limitations and vetoes. Resolve review holds before advancing. A deterministic or automated review does not establish independent biological replication.

Workspace promotion of a frozen Tier 2 method requires verified code/runtime identity, contracts, calibration and independent review for the supported regime. Repository-wide Tier 1 promotion additionally requires reviewed source integration, reproducible CI and maintained regression/calibration evidence. Keep workspace scope visible until repository review passes.
