# Scientific provenance

`provenance.json` identifies the primary study records and original reference
network terms. It contains no empirical expression matrix or network goldens.

The expanded matrix comprises 55 distinct **synthetic** scenarios. Its ground
truth is generated by the trusted runner and returned in memory, outside the
agent workspace. Developmental papers provide scientific context; their data
are not the source of synthetic expression.

Public processed snapshots are counted separately. The ingestion manifests
record source SHA256, file size, selected genes and samples, measurement type,
collection-stage metadata, and unknown specimen identities. Collection age and
published cell-type labels are reference annotations, not true pseudotime or
causal lineage ground truth. These are nonclinical mouse research datasets.

E-MTAB-6798 provides a 121,114,240-byte processed bulk RPKM table using quoted
whitespace. E-MTAB-6967's official processed `atlas_data.tar.gz` is
1,669,415,283 bytes and is outside the initial 1 GB download budget. The author
recommends the MouseGastrulationData package for smaller per-sample derivatives.
Support for H5AD and 10X formats does not imply that those files were available
or downloaded from this study.

Published public task definitions use a portable `snapshot_id` and an exact
`source_manifest_sha256`. Snapshots resolve under `DEVHARNESS_DATA_DIR` when set
to an absolute directory, or the installed benchmarks package's `cache/public`
directory otherwise. The trusted staging API also accepts an explicit absolute
`snapshot_dir` runtime override. The builder never writes that local path into
published task definitions. Missing or changed snapshots fail staging; they do
not silently fall back to synthetic data.

TRRUST mouse data are downloaded only into the ignored cache. The landing page
states noncommercial research use for network edges and separately links a
CC BY-SA footer. This repository does not resolve that difference by inventing
redistribution permission. TRRUST edges are curated literature observations,
not ENCODE measurements, complete context-specific regulatory truth, or proof
of clinical utility. Missing curated edges are not known negatives.
